# Turno — Gerenciador de tarefas

Turno é um painel de organização de tarefas pensado para o ritmo tranquilo de um escritório à noite ou para aquele momento de colocar a vida em ordem depois do trabalho. A interface combina uma estética escura, tons de azul arroxeado e tipografia clara em uma composição com bastante informação, mas organizada para leitura confortável.

O site permite visualizar indicadores de produtividade, acompanhar tarefas pendentes e concluídas, pesquisar e filtrar registros, além de criar, editar, concluir e excluir tarefas. Os dados são carregados e persistidos por uma API REST construída com Express e MySQL.
